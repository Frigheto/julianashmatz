## 🚀 Próximo Passo: Adicionar Vídeo

### ⚡ Rápido (5 minutos)
1. Acesse: https://www.pexels.com/pt-br/videos/
2. Busque: "child learning" ou "kid studying"
3. Baixe um vídeo em HD
4. Renomeie para: `hero-background.mp4`
5. Coloque em: `assets/videos/hero-background.mp4`
6. Abra `index.html` no navegador

**Design quebrado?**
- Limpar cache do navegador
- Testar em modo anônimo
- Verificar console do navegador (F12)
